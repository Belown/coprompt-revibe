No server · scripted model · Titanic exercise

The exercise: Titanic, as in the paper's Fig. 2

Alice owns data preparation and outliers, Bob the feature analysis. The model is a script: these prompts (or close variations) work, others get a message. Click a name to switch to that view. Reset demo… in the ⋯ menu starts over.

  1. Alice: click Run on load data/titanic.csv into df (wait for “Python: ready”).
  2. Alice: hover 1. Deal with missing values, + prompt, type drop columns with missing values in df, press Enter, then Run.
  3. Alice: under 2. Encode: encode categorical features in df and store the result as df_encoded, Enter, Run.
  4. Bob · refer: under 3. Feature transformation: calculate the skewness of all features in df, Enter. Double-click df, Make node, then refer on Alice's encode prompt in the wiki. His prompt and code switch to df_encoded.
  5. Bob · request: under 4. Correlation: plot the correlation matrix of df as a heatmap, Enter. Make df a node, request on Alice's missing-values prompt, note fill missing values instead of dropping the columns.
  6. Alice: the request is in Messages. Change her prompt to fill missing values in df without dropping any rows or columns, Enter. Bob's heatmap regenerates by itself.
  7. Alice: under 5. Deal with outliers: remove outliers of df, Enter. Bob · share: make skewness a node, share on that prompt. Alice: Accept the pop-up; her filter now only uses the skewed columns.
  8. Alice · link: make df in her missing-values prompt a node, double-click df in the encode row of the wiki to select it, then link on that row. Append and store the result as df_filled to the missing-values prompt, Enter: the encode prompt and code follow to df_filled.
  9. Either: the bulb (Explain), the clock (History: diff and restore), the speech bubble (comments).
  10. Alice · code first: + block, type # survival rate by class and df.groupby('Pclass')['Survived'].mean() in its code, then Prompt from code.
